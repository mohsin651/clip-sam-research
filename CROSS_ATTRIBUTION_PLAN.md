# Frozen cross-attribution / cross-dataset transfer

Authorized final matrix: CS and GE on the exact previously evaluated RefCOCO UNC testA/testB, RefCOCO+ UNC testA/testB and RefCOCOg UMD test manifests. All CDA and dense COCO results are reused. No fitting, calibration, exclusion, new variant or source update. Official commits and adapter hashes must match the completed external-baseline signatures.

The original expression is passed verbatim. CS retains its existing official 85-template ensemble around that entire expression and empty-text redundant embedding. GE retains its existing raw-text tokenizer, last layer n=1, native half-precision full-image processing. No shortening or tokenizer truncation is permitted. Context overflow or incompatible maps stop that source/cell and are reported, not repaired.

The unchanged external adapters produce the existing 224 crop map from their full-image representations. Unchanged POS3 (k=3, 32 crop-pixel separation), SAM ViT-B, candidate_features, choose, saved ranker and density threshold operate on that map. All three candidates are identical across selectors within an expression/source. No official CS Text2Points/ViT-H inference is run. Crop-map binary masks use the existing mean rule and are lifted with zero outside the crop for full-image evaluation; this preserves the existing referring-expression protocol. This limits map/fallback coverage even though upstream external encoders see the full image.

Primary metrics: full-image expression-macro referred-instance IoU, Dice, precision, recall, pixel accuracy, P@.5/.7 and unchanged correct/wrong/tied same-category instance overlap proxies. Secondary exact crop metrics retained. Continuous PG/EPG/AP are evaluated on lifted map and crop separately; no continuous SAM scores invented. Every expression, zero map, empty candidate and fallback stays in denominators. Harm is relative to each source's own map, tolerance 1e-8. Candidate accuracy accepts any IoU-optimal candidate within 1e-8, regret uses best IoU minus chosen IoU, inadequate means best<.5.

Use 2,000 paired whole-image resamples, seed 2026, expressions grouped and expression weighting. Primary comparisons SMART-NAIVE, FINAL-SMART, FINAL-NAIVE, NAIVE-MAP; preserve CIs for IoU, Dice, P@.5, harm and instance proxies; SMART-NAIVE also candidate accuracy/regret. No multiplicity adjustment. Supported/negative transfer requires the corresponding IoU CI strictly above/below zero; otherwise no established transfer. No overall score. Pre-existing strict flags are unchanged: RefCOCO+ empty; RefCOCOg strict 2,443 images / 8,894 expressions. Strict subsets are nested, not independent replications. All cohorts are already inspected.

Inference receives stripped image/sentence/text/path manifests and image hashes only. Each source/dataset starts with exactly 20 technical expressions, no GT scoring, reused on resume. Cache native/crop maps before SAM, save all masks, features, points and decisions per expression. Signed source/input hashes govern resume. All six inference cells finish (or disclose a hard failure) before the separate evaluator loads annotation masks. Existing output files are hash-protected.

Examples: up to two per dataset per requested category (CS naive IoU<.5 to final>=.5; GE same; CS final<.5; GE same; fallback avoids harm; multiple-instance incorrect final; long final>=.5; long final<.5), stable closest-to-median final IoU then source/sentence tie-break. Outcome-selected illustrations do not estimate frequency. Missing groups are disclosed.

Stop after this matrix, audit, reports and small galleries. Do not add methods/datasets or optimize from results. Prior backup remains a separate pending task if GitHub authentication is unavailable.
