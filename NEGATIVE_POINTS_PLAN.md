# RefCOCO validation negative-point development protocol

Predeclared before inference. No testA/testB inference or tuning; no changes to frozen CLIP, attribution, SAM, smart ranker, feature definitions, or density fallback. All prior outputs are protected. Development-only conclusions are exploratory.

Cohort: seed 2026, up to 500 UNC validation images with at least one non-crowd referred target and another non-crowd same-category instance each having >=64 pixels in the unchanged CLIP crop. Select images uniformly from sorted eligible IDs, then retain ALL original expressions/references in selected images, without performance filtering. Record overlap with prior cohorts and RefCOCO tests. Save full evaluation and stripped inference manifests before inference. Only category NAME is added to inference inputs, explicitly allowed by the user.

POS3: import original infer_one unchanged. All negative variants retain these exact positive points. Feature extraction receives only the original positive points, preserving the learned feature semantics; negative points only enter SAM with label 0.

Auxiliary regions for NEG_LOW: for each RGB image run SAM at a fixed 3x3 crop grid (coordinates 37,112,187 on each axis), retain the SAM-score winner per seed; remove empty regions or crop area <64 or >80% and greedily deduplicate at crop IoU >0.8. This object-region proposal bank uses no annotations and is shared across expressions. Within each expression choose strongest target-attribution mean-density region as anchor. A competing proposal must have <= half anchor density and IoU <=0.25 with anchor. Use its exclusive area outside anchor as negative support. Order by descending SAM score then seed order. This is a low-target-evidence object-region heuristic, not guaranteed same-category identity.

NEG_REGION: use the three unchanged POS3 SAM candidates. Anchor is highest crop target-attribution mean density. Competing candidates require <=half anchor density and IoU <=0.5 with anchor. Use exclusive area outside anchor; order by increasing density then candidate index. The nested candidates often offer no valid competitor; retain this failure. NEG_LOW and NEG_REGION differ in proposal source and distinctness rule, not fitted parameters.

NEG_CONTRAST: compute frozen attribution for 'a photo of a {category}'. Independently min-max normalize target and generic crop maps. Support = generic >= generic mean AND generic>0 AND target <=0.5*generic. Connected components use 8-neighbor connectivity, area >=64. Order by summed (generic-target) evidence descending. No alternate formula search. POS3 positives stay unchanged to isolate adding negatives.

All rules: negative support components >=64 crop pixels; choose maximum Euclidean distance-transform interior point (at least 2 crop pixels from region boundary), at least 32 crop pixels from every positive/previous negative. Validate rounded original coordinate lies inside lifted inferred support. Select at most one point per connected support region. If fewer than requested k exist, use POS3 unchanged, with no_negative_available=true; do not silently run NEG1 as NEG2. Evaluate k=1 and k=2 only. Save inferred support masks, crop/original point coordinates and exact reasons.

Systems: CLIP plus POS3 and six negative variants, each with SAM-score, frozen smart, and frozen smart+density fallback (22 rows per expression). No selector refit. Save all three candidates per strategy. Technical smoke on exactly 20 expressions without GT scoring, then complete full inference before separate GT evaluation. Hash input images, sources, manifests, frozen models and predictions. Resume only with exact signatures.

Primary original-image instance IoU, correct-instance, P@0.5, harm relative to CLIP. Also Dice/precision/recall/pixel accuracy, wrong-instance/ties, direct changes against matched POS3 selector. Use previous instance metric and length/spatial/attribute/color/clothing lexicons unchanged. Post-hoc negative-point categories: target first, then other same-category, then different-category (including crowds), then background; retain overlapping membership flags too. Report both point-level and expression-level denominators, availability and target-hit rates. No GT affects prompts/selection/fallback.

Candidate oracle for each prompting variant, paired against POS3; combined prompt+candidate oracle includes POS3. Negative-strategy oracle for each fixed selector, separately negatives-only and including POS3. All are analysis-only. Statistics: 2,000 paired whole-image bootstrap resamples seed2026. Multiple comparisons are exploratory; no multiplicity adjustment.

Development decision: CONTINUE only if a negative variant under frozen smart+fallback has positive lower 95% paired bounds for correct-instance AND mIoU versus POS3+same selector/fallback, and the variant's candidate-oracle IoU also has a positive lower paired bound. Rank qualifying variants by mean correct-instance gain, then IoU gain, then name; freeze exactly one without further optimization. Otherwise STOP with all failures retained. This conservative gate is predeclared, not proof of independent test success. Prior RefCOCO tests have already been inspected for the old method; no new test predictions are permitted in this task.

Visuals after evaluation: median-IoU representatives for requested recovery, competitor hit, target hit, contrastive success/failure, ambiguity, long/spatial success/failure categories. Empty categories explicitly reported. Technical geometry panels use inferred regions only, no GT.
