# Smart SAM development and prospective held-out protocol

The previously inspected 500 COCO images are development data only. Preserve every prior experiment. The new test cohort is selected only after fitted models, source hashes and this protocol are frozen.

Candidate features: 18 inference-only values in scripts/smart_sam_core.py, measured on original-resolution SAM candidates and lifted positive attribution. Density uses epsilon 1e-12; empty inside/outside means are zero. Empty-mask agreement is one when both masks are empty. Point containment rounds pixel centers; one-point degenerate maps use zero spread. All failures remain. The linear ranker uses nine nonredundant candidate features; pair context cancels in additive pairwise ranking and is used by the gate instead. Gate uses 14 features. No class, image ID, GT area, GT mask or outcome enters either model.

S0 SAM score, S1 coverage, S2 density ratio, S3 standardized pairwise logistic ranking (C=1, no intercept, reversed training pairs, ties excluded). No hyperparameter search. Five shuffled image folds, seed 42. Each outer fold trains S3 only on its training images. For gate training, four inner image folds cross-fit the ranker within outer training. F0 always SAM, F1 log-density threshold chosen from training deciles plus always/never to maximize gated training mIoU, F2 standardized balanced logistic regression C=1 and fixed probability threshold 0.5. Gates evaluated for both S0 and S3. Final ranker is fitted to all development candidates; final gate is fitted to outer out-of-fold selected development examples. Development estimates remain exploratory because this cohort informed prior feature design.

Choose the final selector and gate using development out-of-fold mIoU, with harm and semantic tradeoffs disclosed. Freeze before selecting heldout IDs. Heldout seed 2026; 500 new images, two targets each, original >=502 crop-pixel and >=25% retention eligibility, excluding all development images. Select from sorted eligible IDs with independent same-seed permutation and target-choice RNGs as the original algorithm. Attribution and SAM implementations/checkpoints remain unchanged; top-three positives, minimum distance 32 crop pixels, three multimask candidates. Center point control optional.

Inference process receives RGB, target text, saved models and GT-free manifest only. Separate evaluation loads GT only after every heldout prediction is complete. No changes after heldout metrics. Primary field is original CLIP crop, foreground IoU pair-macro; semantic success and wrong-object proxies identical to prior evaluation. All methods share masks, images and preprocessing. 2,000 paired whole-image bootstrap resamples, seed 2026. Harm uses delta tolerance 1e-8; worst decile is the mean of the lowest ceil(n/10) deltas. Conditional positive/negative means exclude unchanged cases. Oracle results and outcome-selected representative panels are post-hoc analyses only.
